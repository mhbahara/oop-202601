# Minggu 15: Ulasan Kode Sejawat dan Dokumentasi

Bobot: Observasi 1%, Laporan 1%, Praktikum 3%.

## Tujuan

- Mengulas kode orang lain secara konstruktif.
- Menulis dokumentasi yang dibutuhkan pengguna dan pengembang berikutnya.

## Yang dikerjakan

- Buka pull request dari branch kerja ke `main` di repo Anda (gunakan template PR).
- Ulas **dua pull request** rekan yang ditentukan dosen, memakai `docs/templates/rubrik-ulasan.md`.
- Perbaiki karya Anda berdasarkan ulasan yang diterima atau jelaskan alasan menolak saran.
- Lengkapi README (cara menjalankan), JavaDoc kelas publik penting, dan dokumentasi OpenAPI.

## Aturan pasti (dipakai tes)

- Ulasan memuat masalah nyata dengan merujuk baris kode.
- Respons terhadap ulasan terlihat di riwayat PR.

## Keputusan Anda

- Saran mana yang Anda terima atau tolak.

## Tes

Rubrik ulasan sejawat (dinilai dosen, sebagian diaudit).

Jalankan: `bash scripts/uji.sh` (atau `.\scripts\uji.ps1` di PowerShell).

## Pengumpulan

- Commit dengan format `minggu-15: ringkasan`.
- Isi `catatan/minggu-15.md` dari `catatan/_template.md`, termasuk bagian **Penggunaan AI**.
- Bukti penilaian: CI hijau pada commit terakhir sebelum tenggat.
